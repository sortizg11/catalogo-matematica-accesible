# Cómo trabajar con este repositorio

Repositorio: [Catálogo de Matemática](https://github.com/sortizg11/catalogo-matematica-accesible).

## Qué se guarda aquí

El código del catálogo, el archivo académico original, las guías, las pruebas y las capturas. Las dependencias descargadas y los archivos temporales de pruebas se regeneran y no se suben.

El archivo `Integrales-Primera-parte-accesible.html` ya estaba en el repositorio antes del prototipo. Se conserva intacto. Los ejemplos de la aplicación todavía son muestras provisionales; la incorporación trazable del material original está pendiente.

## Pedir mejoras sin usar comandos

Puedes continuar en el chat del proyecto y describir el cambio. Por ejemplo: «Integra el ejemplo de sustitución del documento original, conserva sus pasos, verifica la accesibilidad y sube el cambio al mismo repositorio».

Cada cambio subido se guarda en un commit, una entrada del historial con los archivos modificados. Las ediciones locales no se sincronizan automáticamente: al pedir una entrega, indica que también se suba a GitHub. El acceso depende de mantener conectada la cuenta y autorizados los permisos del repositorio.

## Consultar lo entregado

1. Abre el enlace del repositorio.
2. Lee el README que aparece en la página principal.
3. Entra en `docs` para ver guías y resultados. En `docs/evidencia` están las capturas.
4. El historial de commits permite identificar las versiones y consultar sus diferencias.

## Código y página web

Guardar el proyecto en GitHub no activa por sí mismo una web navegable. Esta entrega no configura GitHub Pages. Para obtener una dirección del catálogo que puedas abrir sin Terminal, el siguiente paso es autorizar su publicación y comprobar los archivos que deben servirse. El README describe las alternativas de publicación.
