Manual de usuario del catálogo

Consulta los temas con el teclado, el lector de pantalla o el ratón. Abrir el catálogo.

  • Encontrar y estudiar un tema
  • Buscar por voz
  • Leer fórmulas con NVDA
  • Ajustar la lectura y retomar el estudio

Encontrar y estudiar un tema

Escribe el título o un apartado en la búsqueda del inicio. También puedes abrir el temario, desplegar una unidad y seleccionar un tema. Usa Tab y Mayús + Tab para recorrer los controles, Enter para activarlos y Escape para cerrar un diálogo.

Cada tema ofrece teoría, ejemplos, práctica y soluciones. Abre los pasos con Enter o Espacio. Puedes consultar la solución junto al ejercicio.

Buscar por voz

  1. Activa el botón de micrófono y concede permiso si el navegador lo solicita.
  2. Espera el aviso «Escuchando», di el tema y haz una pausa.
  3. Revisa el texto reconocido y selecciona el enlace del resultado.

Para detener el dictado, usa «Cancelar escucha» o Escape. Si la voz no está disponible, escribe la consulta. El navegador puede enviar el audio a su proveedor. El catálogo no guarda grabaciones ni consultas.

Leer fórmulas con NVDA

En modo exploración, usa H y Mayús + H para recorrer encabezados. Al llegar a una fórmula, pulsa Enter para explorarla. También puedes usar NVDA + Alt + M desde el cursor de revisión. Con MathCAT, utiliza las flechas para explorar la expresión y Escape para salir.

Si NVDA no anuncia la fórmula, revisa que MathCAT esté disponible y activo en tu versión. Consulta la guía oficial de NVDA en español.

Ajustar la lectura y retomar el estudio

En «Preferencias» puedes cambiar el tamaño del texto, el contraste y la lectura por pasos. Los atajos vienen activos y se pueden desactivar allí. Alt + Mayús + H abre Herramientas y Alt + Mayús + M muestra u oculta el temario. En «Herramientas» encontrarás «¿Dónde estoy?», que informa el último destino seleccionado o enfocado.

Activa «Guardar este punto de estudio» junto al contenido y luego «Continuar donde quedé» desde el inicio. El marcador se guarda en el mismo navegador cuando el almacenamiento está disponible.
