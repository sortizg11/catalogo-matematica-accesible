# Materiales del portafolio de cálculo

- `fuente/main.tex`: copia intacta del archivo recibido.
- `main-revisado.tex`: versión reorganizada y revisada, compilada correctamente.
- `html/`: once documentos por tema, incluidos los dos de integración existentes. Mantenerlos juntos para conservar los enlaces entre temas.
- `registro.json`: huella de la fuente y sustituciones documentadas.
- `contenidos.json`: datos de los nueve temas nuevos.

El catálogo local se abre mediante el servidor descrito en el README principal; abrir `index.html` directamente no carga los módulos ES. Los HTML de esta carpeta sí se pueden consultar como documentos independientes. Las prácticas sin desarrollo y los contenidos pendientes no se han completado artificialmente. Consultar `docs/incorporacion-portafolio.md` antes de revisión docente o publicación.
